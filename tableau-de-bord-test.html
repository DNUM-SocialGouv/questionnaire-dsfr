Dictionnaire de codage et règles de lecture

Une ligne de Resultats = une participation. Annee désigne la campagne. Date_soumission est remplie à la création par Grist (NOW(), fuseau Europe/Paris).

Q01 à Q09 : 4 = tout à fait d’accord ; 3 = plutôt d’accord ; 2 = plutôt pas d’accord ; 1 = pas du tout d’accord ; 0 = non concerné ; vide = sans réponse. Le code 0 est un statut, jamais une note. Q10_commentaire conserve le texte libre.

Questions : Code relie la question à sa colonne de résultats ; Ordre détermine l’affichage ; Annee permet de conserver les formulations de chaque édition. Pour reconduire une campagne, ajouter les questions de la nouvelle année en conservant les anciennes lignes et réutiliser un Code seulement si le sens reste comparable.
